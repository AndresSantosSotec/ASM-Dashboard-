2. Upload Test (POST /api/estudiante/pagos/subir-recibo)

Test the receipt upload with duplicate prevention.

3. Expected Behaviors

Duplicate Prevention Rules:

  • Receipt Number + Bank uniqueness: No two payments can have the same normalized bank+receipt combination
  • File hash uniqueness: Same student cannot upload the same file twice
  • Cross-student prevention: Receipt numbers are globally unique across all students
  • Normalization: "Banco Industrial" + "BI-123 456" becomes "BANCO INDUSTRIAL:BI123456"
  • No exceptions: Duplicates blocked regardless of previous payment status
